# Gallery photo recovery

Photos that disappeared with the old WordPress Gallery2 embeds (`<wpg2>album</wpg2>`). Current pages are on [tarrant.org.uk](https://tarrant.org.uk). The old public albums were `http://tarrant.org.uk/v/<album>/`.

Two passes:

1. Internet Archive thumbnails, usually 150×150. Gallery2 display images (`/gallery/d/<id>-2/`) almost never play back. Thumbnails (`-4` and `-5`) often do, as `https://web.archive.org/web/<timestamp>im_/<original>`.
2. Larger files from PhotoPrism at `/Users/edward/Developer/play/photoprism-photos/originals`. The files are renamed `YYYYMMDD_HHMMSS_HASH.jpg`. The old folder and filename are in the sidecar YAML next to each file (`storage/sidecar/...yml`, field `OriginalName`). Match on album folder plus filename. Camera names such as `DSCF0001` and `PICT0002` are reused across albums, so a filename on its own is not enough.

A Wayback album link below is an October 2007 (or earlier) capture that actually opened. Later blog snapshots, including 2016, have no gallery HTML. Some album indexes are listed in the CDX API and still return 404 on playback.

Shared files, stored once:

- Mandy's birthday (`mandy40`) is on both [Photos of Mandy's Birthday](https://tarrant.org.uk/2005/09/19/photos-of-mandys-birthday/) and [Computer Out of Action!](https://tarrant.org.uk/2005/08/23/computer-out-of-action/).
- John's birthday 2005 is on both [John's Birthday Treat](https://tarrant.org.uk/2005/11/26/johns-birthday-treat/) and [Eleven Not Ten](https://tarrant.org.uk/2005/12/01/eleven-not-ten/).
- `DSCF1258` from the Wales album is the single photo on the [death announcement](https://tarrant.org.uk/2005/09/16/cindy-tarrant-9th-october-1961-11-september-2005/). The rest of that album is on the computer post.
